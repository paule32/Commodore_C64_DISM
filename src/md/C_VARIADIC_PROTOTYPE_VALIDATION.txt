C variadic prototype validation
===============================

Validated statically:

[OK] C64C grammar accepts a fixed parameter list followed by ELLIPSIS.
[OK] `_function_signature()` distinguishes FunctionPrototypeContext from
     FunctionDefinitionContext through the presence of compoundStatement().
[OK] `int printf(const char *format, ...);` no longer raises the definition
     error.
[OK] A definition with a body and `...` still raises the intended error.
[OK] c64c/compiler.py passes Python syntax compilation.
[OK] Regression tests were added to tests/test_c64c_system_headers.py.

Full ANTLR execution note:

The local validation environment contains antlr4-python3-runtime 4.9.3,
whereas the generated lexer/parser files use the ANTLR 4.13.2 list-based
serialized ATN format. Therefore the complete frontend test cannot start in
this environment. The project runtime must use antlr4-python3-runtime 4.13.2.
