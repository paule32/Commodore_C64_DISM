Stage 175 diagnosis - System.Objects.pas
==========================================

Observed:
  Zeile 10, Spalte 36: mismatched input ';' expecting ':'

Interpretation:
  At `destructor Destroy; virtual;`, an old parser has already consumed
  `virtual` as an identifier/class-field candidate and therefore expects ':'
  when it reaches the final semicolon.

Current repository truth:
  compiler/grammar/PascalParser.g4:
    methodDirective     : VIRTUAL | OVERRIDE
    methodDirectiveList : methodDirective SEMI (methodDirective SEMI)*
    destructorDeclaration ends with SEMI methodDirectiveList?

  parsers/pascal/PascalParser.py:
    generated by ANTLR 4.13.2
    contains RULE_methodDirectiveList, VIRTUAL, OVERRIDE
    destructorDeclaration dispatches to methodDirectiveList().

  x32/pascal/System/System.Objects.pui:
    object_format = coff32
    machine       = i386
    pointer_size  = 4
    object.file   = System.Objects.o
    TObject.Destroy: is_virtual=true, vmt_offset=20

Conclusion:
  Source and intended compiler model are consistent. Runtime parser selection /
  generated parser synchronization is the broken layer. Stage175 corrects that
  layer without changing the Pascal source.
