Important
---------
The actual libruntime_mini.dll was not supplied, so its export table was not
inspected in this environment. Stage181 binds the local Win32 cdecl COFF symbol
`_jit_object_free` to the PE export name `jit_object_free` (without leading
underscore), which matches the Pascal declaration name and standard undecorated
DLL export convention.

At runtime Windows must be able to find libruntime_mini.dll, normally by placing
the correct 32-bit DLL beside the generated PE32 EXE.
