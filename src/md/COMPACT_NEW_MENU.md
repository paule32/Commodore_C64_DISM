# Kompaktes Datei -> Neu Menü

Die erste Ebene von `Datei -> Neu` enthält jetzt:

- Windows PE32
- Windows PE32+
- Amiga 500 ADF
- C= 64 mk68x
- PROLOG
- LOGO
- dBase
- Assembler
- C-64 Character Map
- C-64 Text Screen
- C-64 Pixel Screen
- Textdatei

Jede der acht neuen Gruppen besitzt direkt:

- Projekt: speichert ein bestehendes Projekt und legt sofort ein neues `.pro`-Projekt an.
- Anwendung: erzeugt eine Quelldatei mit der bisherigen Vorlage im Projekt und öffnet sie.
- Programm: erzeugt eine leere Quelldatei im Projekt und öffnet sie.

Die bisherigen Sprachaktionen bleiben über zielbezogene Untermenüs erreichbar. BASIC liegt unter C=64; Pascal/C/LISP sind unter Windows PE32/PE32+ erreichbar und C/Pascal/Assembler auch unter Amiga. PROLOG, LOGO, dBase und Assembler verwenden ihre bisherige Template-Logik über `Anwendung`.
