Messgerät / Oszilloskop

Das Messgerät besitzt die Ports CH1 und COM und arbeitet hochohmig.

  • CH1 an den Messpunkt anschließen.
  • COM an das Bezugspotential oder einen zweiten Messpunkt anschließen.
  • Ein Anschluss kann mit dem Werkzeug Leitung direkt an eine bestehende Leitung gesetzt werden.
  • Beim Start einer Simulation wird die Spannung CH1−COM sowie der digitale Pegel erfasst.

Der Messdialog zeigt aktuelle Werte, Minimum, Maximum und Spitze-Spitze. Bei CMOS-Transienten wird eine echte Zeitachse in Millisekunden dargestellt; bei DC/TTL bleiben einzelne Simulationsstarts als Messpunkte erhalten.
