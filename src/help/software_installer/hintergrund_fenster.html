Hintergrund Fenster

Unter Software Installer → Einstellungen → Hintergrund Fenster bearbeiten Sie die Hintergrundfenster-Konfiguration Ihres Setups.

Mit Hintergrund Fenster anzeigen schalten Sie das Fenster ein oder aus. Wählen Sie im Bereich Fenster zwischen Standard, Eingerahmt und Kiosk.

Im Abschnitt Aussehen können Sie zwischen Statische Farbe, einem Verlauf aus zwei Farben und Bild wählen. Ein Doppelklick auf ein Farbeingabefeld öffnet die Windows-Farbauswahl. Wenn Bild aktiviert ist, kann der Dateipfad eingegeben oder über Durchsuchen ausgewählt werden.

Im Abschnitt Text bestimmen Sie Titel-, Versions- und Fußzeile. Die Felder verstehen Platzhalter wie %ProductName%, %ProductVersion% und %Copyright%. Mit Aa können Sie für jede Zeile eine eigene Schriftart wählen, daneben die Textfarbe. Die Titel- und Versionszeile besitzen jeweils die Ausrichtung Links, Mitte oder Rechts.

Mit OK werden die Daten in den Projektabschnitt Hintergrund Fenster übernommen und das Projekt gespeichert. Bei unbenannten Projekten erscheint zunächst der Speichern-unter-Dialog; bei einem Abbruch bleibt das Projekt als geändert markiert. Abbrechen verwirft alle seit Öffnen des Dialogs vorgenommenen Änderungen. Die Werte werden für eine spätere Setup-Erzeugung gespeichert; eine Ausgabe des Setup-EXE ist hier noch nicht implementiert.
