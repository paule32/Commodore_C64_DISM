Log-Datei

Der Dialog wird über Software Installer → Einstellungen → Log-Datei geöffnet. Die Dialoggeometrie entspricht den Systemanforderungen (620 × 550 Pixel).

Log-Datei anlegen

Mit diesem Kontrollkästchen wird die Log-Datei für das später erzeugte Setup vorgesehen. Ist das Kontrollkästchen aus, bleiben Dateiname und Schreibmodus gespeichert, sind aber im Dialog deaktiviert.

Dateiname

Vorgabe: %TempFolder%\%ProductName% Setup Log.txt. Die Platzhalter bleiben bis zur späteren Installer-Laufzeit unverändert und werden im Editor nicht aufgelöst. Bei aktivierter Protokollierung muss ein Dateiname eingetragen sein.

Schreibmodus

  • Anhängen: Neue Einträge sollen eine bestehende Log-Datei erweitern.
  • Überschreiben: Bei einem neuen Setup-Lauf soll eine bestehende Log-Datei ersetzt werden.

OK übernimmt die Einstellungen in den Projektabschnitt Log-Datei und stößt das bestehende Projektspeichern an. Abbrechen verwirft die noch nicht übernommenen Änderungen. Hilfe öffnet dieses Hilfethema.

Hinweis: Das tatsächliche Schreiben einer Log-Datei durch ein erzeugtes Setup ist nicht Teil dieses Konfigurationsdialogs.
