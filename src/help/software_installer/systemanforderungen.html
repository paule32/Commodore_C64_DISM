Systemanforderungen

Dieser Dialog wird unter Software Installer → Einstellungen → Systemanforderungen geöffnet.

Betriebs-System

Wählen Sie mit den Checkboxen im Baum die unterstützten Windows-Desktop- und Server-Versionen. Ein Haken auf einem übergeordneten Eintrag aktiviert dessen Untereinträge. Teilweise ausgewählte Elternknoten werden entsprechend markiert.

System-Prüfungen

RAM wird in MB, Bildschirm Weite und Bildschirm Höhe in Pixel sowie Farbtiefe in BPP angegeben. Der Wert 0 bedeutet, dass für das jeweilige Feld keine Mindestanforderung gesetzt ist. Die Option Benutzer muss Adminrechte haben legt fest, ob Administratorrechte vorausgesetzt werden.

Benutzer benachrichtigen

Wählen Sie entweder Benutzer warnen und fortfahren oder Benachrichten und Setup abbrechen. Die beiden Optionen schließen sich gegenseitig aus.

OK speichert den Projektabschnitt Systemanforderungen und löst wie beim Hintergrund-Fenster-Dialog das Projektspeichern aus. Abbrechen verwirft die noch nicht übernommenen Änderungen. Der Dialog konfiguriert zukünftige Setup-Prüfungen; eine Setup-Laufzeitprüfung wird hier nicht ausgeführt.
