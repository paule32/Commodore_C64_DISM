Wizard Seite 7 – System Anforderungen

Aktivieren Sie nach Bedarf Un-Install unterstützen, Log-Datei während der Installation führen und Benutzer warnen, wenn Administrator-Rechte erforderlich sind.

Im Baum unter Wählen Sie das/die gewünschte / erforderliche System sind Windows Desktop und Windows Server hierarchisch angeordnet. Ein Klick auf die Checkbox einer Gruppe übernimmt den Zustand auf alle untergeordneten Elemente. Bei gemischten Zuständen wird der Elternknoten teilweise ausgewählt angezeigt.

Als Anfangsauswahl sind Windows 10 und Windows 11 gesetzt. Die angebotenen Versionen sind frei wählbare Zielangaben; die spätere Setup-Engine muss die Kompatibilität zur Laufzeit prüfen.

Fertigstellen übernimmt alle sieben Wizard-Seiten in das ungespeicherte Installer-Projekt. Anschließend kann das Projekt über Strg+S dauerhaft gespeichert werden.
