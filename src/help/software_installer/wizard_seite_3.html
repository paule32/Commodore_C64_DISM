Wizard Seite 3 – Quelldateien

Geben Sie das Verzeichnis der Quelldateien an, die das Setup später installieren soll. „Wählen“ öffnet die Dateisystem-Verzeichnisauswahl.

Die Option Einbeziehung der Unterverzeichnisse speichert, ob das Setup später auch Unterordner berücksichtigen soll. Diese beiden Einstellungen werden unter general.source_directory und general.include_subdirectories gespeichert.

„Weiter >“ öffnet „Fenster Einstellungen“, „< Zurück“ die Plattformauswahl. Die Werte bleiben beim Blättern erhalten.
