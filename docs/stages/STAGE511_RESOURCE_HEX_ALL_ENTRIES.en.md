# Stage 511 – Hex View for All Compiled Resources

The resource editor now has **Show all resources** enabled by default. `format_resource_collection_hex(...)` renders all compiled resources consecutively in the Hex tab, with type, ID, language, and bytes. Disable the checkbox to switch to a single-resource view by selecting a leaf, or to a type-group view by selecting a parent such as `STRINGTABLE (6)` or `MENU (4)`. Editing RC source, switching codepages, or adding resources refreshes all three views consistently. Tests cover aggregation, grouping, selection, and binary output.
