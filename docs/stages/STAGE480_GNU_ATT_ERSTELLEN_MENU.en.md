# Stage 480 – GNU AT&T Syntax and the Build Menu

Introduces a GNU AT&T assembly mode alongside existing syntax options, with selection controlled by project settings. The main **Build** menu gains the relevant actions in a defined order. The assembler output and subsequent compile/assemble/start flow must reflect the selected syntax rather than mixing Intel operands with AT&T directives. Regression checks cover menu routing, saved settings, and generated assembly examples. Detailed implementation and limitations remain in the linked German source documentation.
