# Stage 444 – Roman Numerals: Dark Mode and Column Alignment

The read-only, copyable Roman Numerals learning widget now responds to dark mode with a readable palette; light mode restores bright backgrounds and dark text. Fixed tab stops had caused misalignment in the six columns formed by three number/Roman-numeral pairs. They are replaced with appropriate column sizing; the separate seven-symbol header (`I V X L C D M`) receives its own alignment. Text remains horizontally scrollable when the dock is narrow. No other mathematics tree structures are changed. Tests focus on theme and table layout.
