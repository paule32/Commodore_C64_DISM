# Stage 418 – STA Reducer in C64 Project Settings

**Basis:** `d64_dism_asm_417.zip` (see the German release notes for the exact baseline).

A new **STA reducer** checkbox appears in the C64 compiler optimizer settings for each 68000/68010/68020/68030 profile. It is disabled by default, stored under `Settings.C64.<Profile>.Compiler.Optimizer`, and forwarded as `sta_reducer` to `compile_basic_to_assembly()`. The PRINT/string optimizer switch remains independent.

When enabled, repetitive `STA` sequences generated by software-sprite DRAW/ERASE may be encoded into compact literal and run-length tables with a small MOS6510 decoding routine. Literal groups use byte counts 1–127; repeated runs use a separate encoded count. Compression is selected only when useful. Disabling it preserves Stage-417 instruction generation. Tests compare decompression, generated bytes, and behavior under both settings.
