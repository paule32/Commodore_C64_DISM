# Stage 432 – dBASE Open-File Dialog: Dark Theme

**Basis:** `d64_dism_asm_431.zip` (see the German release notes for the exact baseline).

The dBASE file-selection dialog is adapted to the application's dark appearance. File and directory lists, labels, selection states, input fields, and buttons are styled consistently so text remains readable in both light and dark themes.

Existing file choice and path validation behavior remain intact. Automated tests focus on the dialog's style and source structure; actual native rendering on Windows should be checked.
